# Introduction

A future project designed to make a small monitor for a PC or laptop. Somewhere around 7 inches and used to display discord, sounds, music, UI, clock and so on.

The first prototype can be low power and using OLED, or ePaper but the connection with computer will be more difficult.

One idea is to use the Scuttle project board, but a hdmi connector needs to be added somehow then.

And last idea is to use a already built system, which is cheaper and more logical.
